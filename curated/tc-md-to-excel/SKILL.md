# TC-md-to-excel

将标准 Markdown 格式的测试用例批量转换为带样式的 Excel 文件。

## 触发条件

- 用户提供 Markdown 测试用例文件，要求转换为 Excel
- 用户要求批量生成测试用例编号
- 用户提到"测试用例转Excel"、"用例导出"、"tc to excel"等相关意图
- 用户提供了符合模板格式的 Markdown 测试用例文件

## Markdown 格式规范

测试用例 Markdown 文件必须遵循以下结构（详见 `assets/case_template.md`）：

```markdown
# 所属模块

## 功能点

### 用例标题

- [Px] 前置条件 | 操作步骤 | 预期结果 | 执行结果
```

### 字段说明

| 符号                      | 含义                                |
| ----------------------- | --------------------------------- |
| `#`                     | 所属模块（一级标题）                        |
| `##`                    | 功能点（二级标题）                         |
| `###`                   | 用例标题（三级标题）                        |
| `[Px]`                  | 优先级：P0 必测 / P1 重要 / P2 一般 / P3 可选 |
| `\|`                    | 字段分隔符（前置条件、操作步骤、预期结果、执行结果）        |
| `;` 或 `；`               | 同一字段内多条内容的分隔符                     |
| `- [x] 通过 - [ ] 未通过`    | 测试通过                              |
| `- [ ] 通过 - [x] 未通过`    | 未通过                               |
| `- [ ] 通过 - [x] 未通过 原因` | 未通过：原因                            |

## 执行流程

### 1. 确认输入

从用户获取以下信息：
- 测试用例 Markdown 文件或目录路径
- 用例编号前缀（默认 `TC`）
- 输出路径（默认 `{输入目录}/excel-case/{目录名}_测试用例_{时间戳}.xlsx`）

### 2. 运行转换脚本

执行 `scripts/tc_md_to_excel.py`：

```bash
python scripts/tc_md_to_excel.py [测试用例目录] [--prefix TC] [--output 输出路径.xlsx]
```

**参数说明：**

| 参数 | 缩写 | 默认值 | 说明 |
|------|------|--------|------|
| `case_dir` | - | `.`（当前目录） | 测试用例所在目录 |
| `--prefix` | `-p` | `TC` | 用例编号前缀 |
| `--output` | `-o` | 自动生成 | 输出 Excel 路径 |

### 3. 文件名匹配规则

脚本自动扫描目录中符合以下命名模式的 `.md` 文件：
- `testcase*.md`
- `测试用例*.md`
- `用例_*.md`
- `需求确认*.md`
- `Spec-*.md`
- `TC-*.md`
- `test_case*.md`

若用户文件名不符合规则，直接读取指定文件运行脚本时，可通过传入单个文件所在目录来触发扫描。

### 4. 输出格式

Excel 包含 9 列：

| 列 | 字段 | 说明 |
|----|------|------|
| A | 用例编号 | 自动生成，格式 `{前缀}-{模块拼音首字母}-{三位序号}` |
| B | 所属模块 | 来自 `#` 标题 |
| C | 功能点 | 来自 `##` 标题 |
| D | 优先级 | P0-P3，带颜色标记 |
| E | 用例标题 | 来自 `###` 标题 |
| F | 前置条件 | 分号分隔内容自动编号 |
| G | 操作步骤 | 分号分隔内容自动编号 |
| H | 预期结果 | 分号分隔内容自动编号 |
| I | 执行结果 | 通过/未通过/备注 |

### 5. 样式说明

- 表头：蓝色背景白色粗体，居中对齐
- 优先级列：P0 红色 / P1 黄色 / P2 绿色 / P3 灰色
- 执行结果列：测试通过绿色 / 未通过红色
- 首行冻结 + 自动筛选
- 所有列自动换行、统一边框

## 依赖

- Python 3.8+
- `openpyxl`（Excel 生成）
- `pypinyin`（模块名拼音首字母提取）

安装：`pip install openpyxl pypinyin`

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| `ModuleNotFoundError: openpyxl` | 执行 `pip install openpyxl` |
| `ModuleNotFoundError: pypinyin` | 执行 `pip install pypinyin` |
| 未找到测试用例文件 | 检查文件名是否符合匹配规则，或确认目录路径正确 |
| 用例编号模块缩写不正确 | 检查 `#` 标题是否为中文，pypinyin 会自动处理中英文混合模块名 |
| 编码错误 | 脚本自动尝试 UTF-8 和 GBK 编码读取文件 |
